# plan: 初めてのPCあそび（トラックパッド・ポインター編）

作成日: 2026-07-25
対象ブランチ: claude/mac-kids-pointer-app-mnb2yr

## 1. 前提（CLAUDE.md確認済み）

- ペルソナ: 2歳以上、初めてPCに触れる子ども。操作できるのはトラックパッドでポインターを適当に動かすこと、キーボードを適当に叩くことの2つのみ。
- 厳守事項: plan をファイル化する（本ファイル）／他ブランチのコードは参照しない／MEMORYは参照しない。
- 対象OS: Mac専用デスクトップアプリ。

上記ペルソナの操作能力（ポインター移動・キー連打のみ）を前提に、メニュー操作やクリックの正確性を要求しない設計とする。

## 2. 技術スタック選定

- **Electron + プレーンJS（ESモジュール、ビルドツールなし）**
  - 理由: Canvas / Web Audio API がそのまま使え、トラックパッドのpointermoveや連打キーイベントの実装が容易。ネイティブSwift/AppKitはこの実行環境（Linux, Xcode無し）でビルド・検証が一切できないため採用しない。
  - `electron-builder` の `build.mac` 設定でビルド対象をmacのみ（dmg/zip, arm64+x64）に限定し、「Mac専用アプリ」という要件を配布物のレベルで担保する。
  - レンダラーはバンドラ無しのネイティブESモジュールで実装し、依存を最小化（ロジック単体テストが書きやすい）。
- **テスト**: vitest でレンダラーの純粋ロジック（パーティクル物理、色相計算、音階マッピング）を単体テスト。加えて Playwright(Chromium) でレンダラーHTMLを直接開き、pointermove/keydown をディスパッチしてエラーなく動作すること・エフェクトが発火することをスモーク確認。
- **Electron起動確認**: この環境にはXvfbがあるため `xvfb-run` で実際に `electron .` を起動し、クラッシュしないことを確認する（macOS実機での最終確認は別途ユーザー側で実施）。

## 3. 機能仕様（v1: ポインターで遊べる機能）

- 画面: メニューやボタン等の「読める・狙って押す」UIは一切置かない。起動したら即座に全画面キャンバスの遊び場が表示される。
- **ポインターの軌跡エフェクト**: トラックパッドでポインターを動かすと、カラフルな星/丸のパーティクルが軌跡として発生し、ふわっと浮かびながらフェードアウトする。動かす速さに応じて量・大きさが変化し、「動かすと楽しい」フィードバックを作る。
- **クリック/タップ時のバースト**: トラックパッドをタップ（クリック）すると、その場所で花火のようにパーティクルが弾ける（誤操作扱いにはせず、押しても楽しい要素として許容）。
- **キー連打エフェクト**: 何かキーを押すたびに、画面上のランダムな位置にカラフルな図形（星・丸・ハート）がポップして消える。音は五音音階（ペンタトニック）にマッピングし、どのキーを叩いても不協和音にならず「連打しても心地よい」ようにする。
- **アイドル演出**: 一定時間操作が無いと、ゆっくり漂う演出を入れ、放置していても画面が寂しくならないようにする。
- **音**: 外部音源ファイルを使わず Web Audio API のオシレーターで生成（短いアタック/ディケイのやさしい音色、マスター音量を絞る）。
- **誤操作対策**: アプリのメニューは「アプリを終了(Cmd+Q)」と「フルスクリーン切替」のみを明示的に定義し、それ以外のOS標準ショートカット（最小化・閉じる等のアクセラレータ）は割り当てない。これによりキー連打で意図せずアプリが最小化・終了しにくくする。

## 5. 実装ステップ

1. package.json 作成（Electron, electron-builder, vitest, playwrightを devDependencies に追加）。`build.mac` をdmg/zip限定に設定。
2. `src/main/main.js`: BrowserWindow生成、最小メニュー定義（Quit / フルスクリーン切替のみ）、index.htmlロード。
3. `src/renderer/lib/*.js`: パーティクル物理・色相計算・音階マッピングを副作用なしの純粋関数として実装。
4. `src/renderer/app.js`: pointermove / click / keydown をリッスンし、lib関数を使って canvas に描画、requestAnimationFrameループ、アイドル演出、テスト用フック `window.__pcGame` を公開。
5. `src/renderer/lib/sound.js` + Web Audio 連携。
6. `index.html` / `style.css`: 全画面キャンバス、余計なUIなし。
7. vitest による単体テスト作成・実行。
8. Playwright スモークテスト作成・実行（renderer HTMLを直接開いてイベント発火確認）。
9. `xvfb-run` で `electron .` を実際に起動しクラッシュしないことを確認。
10. README.md にセットアップ・起動・mac向けビルド（`npm run dist:mac`、実機での実行が必要である旨）を記載。
11. コミット・プッシュ。
