# ポインターであそぼう (play-the-pc)

初めてPCに触れる子ども(2歳〜)向けの、トラックパッド操作を楽しむ**Mac専用**デスクトップアプリです。

トラックパッドでポインターを適当に動かすだけ・キーボードを適当に叩くだけで、
必ず楽しい反応が返ってくることをいちばん大切にしています。

## あそびかた

| 子どもの操作 | 画面の反応 |
|---|---|
| トラックパッドでポインターを動かす | 大きな星カーソルが虹色のキラキラの軌跡を引く |
| ふわふわ漂うシャボン玉にポインターで触れる | ポンッと弾けて紙吹雪(クリック不要。弾けた分は自動で補充) |
| トラックパッドを押し込んでしまう(クリック) | 花火がドーンと上がる |
| キーボードをどれでも叩く | 押したキーの大きな文字や絵文字が現れ、心地よい音階が鳴る |

効果音はすべてWeb Audioでリアルタイム合成しており、キーを適当に連打しても
ペンタトニック音階でメロディーのように聞こえます。

## 保護者の方へ(終了のしかた)

- **Escキーを3秒間押し続ける**と、カウントダウン表示ののちアプリが終了します
- **Cmd + Q** でも終了できます
- アプリは全画面(キオスクモード)で起動し、上記以外のショートカット(Cmd+W / Cmd+H など)、
  右クリックメニュー、ピンチズームは無効化されるため、お子さまの誤操作でアプリの外に出ることはほぼありません

## セットアップ(macOS)

Node.js(v20以上推奨)がインストールされた状態で:

```bash
npm install
npm start        # 全画面キオスクモードで起動
```

開発用にウィンドウモードで起動する場合:

```bash
npm run dev      # PLAY_DEV=1 でウィンドウ表示
```

配布用の .app / .dmg をビルドする場合:

```bash
npm run dist     # dist/ にmacOS向けバイナリを生成
```

## 開発

- 技術スタック: Electron + Vanilla JS + Canvas 2D(フレームワーク・バンドラーなし)
- 設計や機能仕様の詳細は [docs/plan.md](docs/plan.md) を参照してください
- 画面ロジックの自動テスト(Chromiumヘッドレス):

```bash
npm test
```
