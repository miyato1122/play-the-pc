# Plan: ポインターであそぼう(Play the PC v1)

作成日: 2026-07-25
対象ブランチ: `claude/mac-kids-pointer-app-qzy615`

## 経緯・ゴール

子どもがMacBook Airのトラックパッドでポインターを適当に動かして楽しんでいる。
その「適当に動かす」だけの操作が、もっと楽しくなるMac専用デスクトップアプリを作る。

## ペルソナ(CLAUDE.mdより)

- 2歳以上の初めてPCに触れる子ども
- できる操作は次の2つだけ
  - トラックパッドを指でなでて、ポインターを適当に移動する
  - キーボードを適当に叩く

→ 「クリック」「ドラッグ」「文字入力」などの正確な操作は前提にしない。
ポインターを動かすだけ・キーを叩くだけで、必ず楽しい反応が返ることを最優先とする。

## 技術選定

**Electron + Vanilla JS + Canvas 2D** を採用する。

| 観点 | 理由 |
|---|---|
| Mac専用デスクトップアプリ | Electronのkiosk/fullscreenでMac上の全画面アプリにできる。electron-builderでmacOS向け(.app/.dmg)のみをビルド対象にする |
| 子ども向けの安全性 | kioskモード+ショートカット抑制で、誤操作によるアプリ切替や終了を防げる |
| 表現力 | Canvas 2Dで数百個のパーティクルを60fpsで描画でき、キラキラした演出が作りやすい |
| 音 | Web Audio APIで効果音を合成する。音声アセット不要で、キー連打でも心地よい音階(ペンタトニックスケール)にできる |
| 検証可能性 | 画面部分は純粋なWebページなので、開発環境(Linux)でもChromium+Playwrightで自動テストできる |
| 依存最小 | フレームワーク・バンドラーなし。誰でも読める素のJSで保守しやすい |

## 機能仕様(v1)

画面は夜空のような1枚のシーン。モード切替なし(ペルソナはメニュー操作ができないため)。

- **F1: レインボートレイル** — ポインターを動かすと、虹色に変化するキラキラの軌跡(星・光の粒)が尾を引く。ポインター自体も大きな星カーソルに置き換える(小さな矢印は2歳児には見えづらいため)
- **F2: シャボン玉** — 画面内をカラフルなシャボン玉(中に動物や果物の絵文字入り)がふわふわ漂う。**ポインターが触れるだけで**ポンッと弾けて紙吹雪+効果音。クリック不要。弾けた分は自動で補充され、遊びが途切れない
- **F3: 花火** — クリック(トラックパッドを押し込んでしまった時)は花火がドーンと上がる。誤クリックすら楽しい反応にする
- **F4: キーボードあそび** — どのキーを叩いても、大きなカラフルな文字(押したキー)や絵文字が画面にポンッと現れて消える。同時に音階(ペンタトニック)が鳴り、適当に連打してもメロディーっぽく心地よい
- **F5: 効果音合成** — ポップ音・花火音・音階をWeb Audioでリアルタイム合成。外部音源ファイルなし
- **F6: 子ども向け安全設計**
  - 全画面kioskモードで起動(Dockやメニューバーに触れない)
  - Cmd/Ctrl系ショートカット(Cmd+W, Cmd+H等)を抑制(Cmd+Qのみ許可=保護者の標準的な終了手段)
  - ピンチズーム無効、右クリックメニュー無効、テキスト選択無効
  - **保護者向け終了操作**: Escキーを3秒間押し続けると、カウントダウンリング表示ののちアプリ終了(子どもが偶然実行しにくく、保護者には簡単)

## 構成

```
play-the-pc/
├── docs/plan.md            # 本ファイル
├── package.json            # scripts: start / test / dist(mac)
├── main.js                 # Electronメイン: kiosk全画面・ショートカット抑制・終了IPC
├── preload.js              # contextBridgeで終了APIのみをrendererへ公開
├── renderer/
│   ├── index.html
│   ├── css/style.css       # 背景・キー文字アニメ・終了オーバーレイ
│   └── js/
│       ├── audio.js        # Web Audio効果音合成(音階・ポップ・花火)
│       ├── particles.js    # パーティクルシステム(軌跡・紙吹雪・花火)
│       ├── bubbles.js      # シャボン玉の生成・浮遊・ホバー判定・補充
│       ├── keys.js         # キー押下→大きな文字/絵文字の表示
│       └── app.js          # 入力配線・描画ループ・星カーソル・Esc長押し終了
└── test/run-tests.mjs      # Playwright+Chromiumによる自動テスト
```

- セキュリティ: `contextIsolation: true` / `nodeIntegration: false` / `sandbox: true`。rendererに公開するのは「終了」IPCのみ
- Mac専用: electron-builderのビルドターゲットはmacのみ。開発時はブラウザ/他OSでも画面確認可能(`PLAY_DEV=1`でウィンドウモード)

## テスト方針

開発環境ではmacOS実機がないため、renderer(画面ロジック)をChromiumヘッドレスで自動検証する:

1. ページが正常にロードされ、canvasとデバッグAPIが存在する
2. ポインター移動で軌跡パーティクルが発生する
3. シャボン玉にポインターが触れると弾ける(pop数が増える)
4. クリックで花火パーティクルが発生する
5. キー押下で文字グリフが表示される
6. Esc長押しで終了オーバーレイが表示される

macOS実機での最終確認(kiosk起動・Cmd+Q・Esc長押し終了)は利用者側で `npm start` により行う想定。
